# PC 储能大屏风格

样例工程：`aicoding/pc-nanjing-metro-network-control` 的首页大屏（`HomeView` + `ScreenHeader` + `KpiBar` + `BasePanel`）。

本 skill 只覆盖这块大屏。登录页、后台列表（`--desk-*`）不是大屏规格。

生成或改版前，先读本文件，再按需打开对应参考。样式以参考文件里的代码为准，禁止凭记忆改数值、圆角、渐变或字号。

## 改版已有大屏

用户拿现成页面来套这套皮肤时，只换样式，不改信息架构。下面三条优先于后文「样例是 6 张 KPI、5 块面板、4×2 栅格」。

### 不许丢内容

源页面上的每一块内容都留下，并且留在原来的位置。禁止为了凑样例的 6 张 KPI、5 块面板或 4×2 栅格，删掉、合并，或搬去别的面板。

标题下方有几张卡，改完还是几张，还在那一行。源页面若是 6 张等宽指标加 1 张更宽的天气卡，就保持这 7 张和原来的相对宽度，天气卡仍在这一行的右侧。只把每张卡的外框换成 KPI 皮肤：高 `100px`、四角直角、渐变、青边、左竖线、左上和右下 `10px` 直角拐角。卡里的名称、数字、占比、占比条、天气各项都还在。

下面有几块面板、谁在左中右、上下谁高谁矮，按源页面的占比留着。外框换成 [chrome-panel.md](chrome-panel.md)。不要改成样例的 4 列 × 2 行。

### 不许杜撰告警态

`is-alarm`、红色径向底、闪烁红框、整张卡变红，只有源内容本身已经是告警状态才用。一张卡在统计「某一类告警有多少条」，不表示这张卡要用告警皮肤。不要把第一张卡单独做成红色。

源页面里数字本来的红/琥珀区分，用色板里的 `#ff6b6b`、`#f5c15a` 画在数字、左竖线或占比条上。卡片底仍是普通 KPI 渐变，所有同类卡同一张皮。

### 面板外框 1:1

标题下面的每一块面板，外框必须和样例 `BasePanel` 同一套数值。禁止写成「看起来差不多」。改完对着样例截图看四角：几乎是直角，只有对角两只青色直角括号。

| 部位 | 锁定值 |
|---|---|
| `.shell`、`.panel` 圆角 | `0`。右上、左下是直角，不要 `2px` 圆角 |
| 背景 | `linear-gradient(180deg, rgba(12, 48, 86, 0.55), rgba(4, 18, 38, 0.88))` |
| 描边 | `1px solid rgba(90, 196, 255, 0.45)` |
| 阴影 | `var(--shadow-soft)` |
| 拐角 | 只有左上、右下。`12×12`，线宽 `2px`，颜色 `#7ee7ff`，直角，盖住边框外侧 `1px`。不要四角，不要把括号做成圆角 |
| 标题栏 | 高 `42px`，左右 padding `14px`，不加上下 padding。序号、中文、英文在同一行内共用基线，`align-items: center` 垂直居中。不要用 `translateY` 挪文字 |
| 序号 | `11px`、字距 `0.08em`、`#3ad4ff`、class `num` |
| 标题 | `15px` / `600` / 字距 `0.12em` / `#e7f6ff`，光晕 `rgba(58, 212, 255, 0.35)` |
| 英文 sub | `10px`、字距 `0.08em`、`#5d8eaa`、大写 |
| 标题下分隔线 | 左右各内缩 `14px`，高 `1px`，`transparent → rgba(90, 210, 255, 0.55) → transparent` |
| 面板内列表、单元格、横条 | 圆角 `0` |
| 左侧竖线 | 没有。竖线只属于 KPI 卡 |

下面面板拐角是 `12×12`，线宽 `2px`，只在左上和右下。标题下指标卡不加拐角。右上、左下保持直角。顶栏胶囊和按钮圆角 `2px`。Logo 是 `11px`。状态点是圆。饼图扇区圆角是 `6`。

## 技术栈

Vue 3 + `<script setup lang="ts">` + Vite + Tailwind 3 + Element Plus + Remix Icon。

字体只引入：

- `@fontsource/instrument-sans` 的 400 / 500 / 600
- `@fontsource/ibm-plex-mono` 的 500 / 600
- `remixicon/fonts/remixicon.css`

数字用 `IBM Plex Mono`（class `num`）。界面文字用 `Instrument Sans`，中文回退 `PingFang SC` / `HarmonyOS Sans SC` / `Microsoft YaHei`。

Tailwind 的 `slate` / `cyan` / `sky` / `emerald` / `amber` / `red` 已被样例改写。必须整段复制 [tokens.md](tokens.md) 里的 `theme.extend`。使用默认 Tailwind 色值会偏色。

## 生成前先确认

缺任何一项就停下来问用户，禁止补造文案、改列数或改布局。

| 槽位 | 样例 | 未给出时 |
|---|---|---|
| 英文眉题 | `Factory Energy Center` | 保持样例，并询问是否更换 |
| 中文主标题 | `厂区智慧能源监控中心` | 保持样例，并询问是否更换 |
| 顶栏左侧状态胶囊 | 运行状态、在线电表、数据链路、刷新周期 | 保持这四项；增删改先问 |
| 顶栏右侧 | 时钟、声音开关、全屏、用户、退出 | 保持这五项；拿掉或替换先问 |
| KPI 条数 | 6 张，一行，高 `100px`，`grid-cols-6` | 新做大屏时不是 6 张先问，禁止改高度。改版已有页面时以源页面张数为准，不许删卡 |
| 每张 KPI | 名称、Remix 图标、单位、强调色、副文案、小数位 | 缺字段就问。强调色只能用 [tokens.md](tokens.md) 色板 |
| 下面板数量和占位 | 4 列 × 2 行，上行 `1.48fr`、下行 `0.78fr` | 新做大屏时与样例不同先问，禁止改 `gap: 12px` 和行高比。改版已有页面时沿用源页面的块数和占比，外框仍 1:1 |
| 每块面板 | 序号 `01`–`05`、中文标题、英文 sub、内容类型 | 缺内容类型就问 |
| 全屏告警条 | 样例有红色逆流告警 | 用户没要求同类告警时不要做 |

主标题超过 10 个汉字，或眉题长于 `Factory Energy Center` 时，先问用户：侧栏仍固定 `600px`，标题会压到两侧胶囊。

## 锁定项

以下数值和选择器禁止改。完整代码在对应参考里，生成时整段复制。

- 画布：设计宽 `1920`，高度随窗口撑满，`transform-origin: top left`。见 [layout.md](layout.md)
- 背景、48px 网格、上下径向光、内缩 8px 的青色描边
- 顶栏：高 `76px`，左右各 `600px`，标题绝对居中。见 [chrome-header.md](chrome-header.md)
- 眉题：`10px` / `500` / 字距 `0.28em` / `#7ee7ff`，两侧各一条 `36×1px` 渐变线
- 主标题：`28px` / `600` / 行高 `1.15` / 字距 `0.28em` / `#f4fbff` / 青色文字光晕
- KPI 卡：高 `100px`、纵向渐变、`1px` 青边、左竖线 `2px`、只保留左上和右下 `10px` 拐角。见 [chrome-kpi.md](chrome-kpi.md)
- 面板：同一套渐变和青边。拐角画在 `.panel` 上，左上和右下 `12×12`、线宽 `2px`。标题栏高 `42px`，不加上下 padding。序号、中文、英文放在同一个 `.head-main` 里用 `line-height: 1` 共用一条基线，由标题栏 `align-items: center` 垂直居中。不要各自写成标题栏高度的行高，也不要用 `translateY` 把文字往上挪。后台主题里的 `.panel { padding }` 必须挂在 `.board-page` 下，不能写成 `html.sidebar-color-blue .panel`，否则大屏标题会被顶下去。标题下有一条中间亮、两边淡出的分隔线。见 [chrome-panel.md](chrome-panel.md)
- 间距：舞台 `padding: 0 16px 12px`，舞台、指标卡、面板网格都是 `gap: 12px`。标题下指标卡高 `100px`
- 圆角：指标卡和下面面板的右上、左下是直角，`border-radius: 0`。标题下指标卡不加拐角括号。下面面板只在左上和右下加 `12×12` 直角括号，线宽 `2px`。胶囊是 `2px`。Logo 是 `11px`。饼图扇区是 `borderRadius: 6`，见 [patterns.md](patterns.md)

面板没有左侧竖线。竖线只属于 KPI 卡。拐角是 CSS 边框括号，不是图标字体，并且只有对角两个，不要补成四角。

## 可替换项

只替换这些，容器 class 和样式保持不动。

- 眉题字符串、主标题字符串
- 状态胶囊里的文案和状态点颜色（颜色仍用色板：正常 `#2ee59a`、等待 `#f5c15a`、告警 `#dc2626`）
- KPI 的 `label` / `icon` / `unit` / `color` / `value` / `decimals` / `sub`
- 面板的 `title` / `sub` / `index` / 默认插槽内容 / `#extra` 插槽
- 面板内部的业务数据

面板内部优先复用 [patterns.md](patterns.md) 的行、单元格、表格、芯片、横条、竖条、内层卡。新的业务图放进 `BasePanel` 的 body，描边、底色、字号、字色仍落在色板和 patterns 里。

## 步骤

1. 用上面的表核对用户需求。有缺口就只提问，不写页面。
2. 新项目或新页面时，按参考文件复制，不要重写一份「相似」样式：
   - [tokens.md](tokens.md)：`:root`、字体、`num` / `chip` / `cell` / `label`、动效、Tailwind 色板
   - [layout.md](layout.md)：`useScreenScale`、页面壳、背景、网格
   - [chrome-header.md](chrome-header.md)、[chrome-kpi.md](chrome-kpi.md)、[chrome-panel.md](chrome-panel.md)
   - [behaviors.md](behaviors.md)：时钟格式、数字滚动
3. 把用户确认过的文案和数据填进槽位。
4. 面板内容用 [patterns.md](patterns.md)。不要另做一套卡片皮肤。
5. 用下面的验收清单自检。有一项对不上就改回参考代码，不要微调出新风格。

## 验收

- 顶栏高 `76px`；眉题两侧有 `36px` 渐变线；主标题 `28px`、字距 `0.28em`、颜色 `#f4fbff`
- 左右功能区各 `600px`，标题在页面水平正中
- KPI 一行 6 张（或用户确认过的数量）、高 `100px`；每张有左竖线；拐角只在左上和右下。改版时源页面有几张就还是几张，没有被挪走
- 没有任何一张卡因为「这个数是告警条数」被加上 `is-alarm` 或红色卡底
- 指标卡和面板右上、左下是直角。标题下指标卡不加拐角。面板拐角 `#7ee7ff`、`12×12`、线宽 `2px`，只在左上和右下
- 面板渐变是 `rgba(12, 48, 86, 0.55)` 到 `rgba(4, 18, 38, 0.88)`；描边 `rgba(90, 196, 255, 0.45)`
- 面板标题栏高 `42px`，标题 `15px`、字距 `0.12em`、颜色 `#e7f6ff`；序号和标题在同一条基线上并垂直居中；标题下有一条居中淡出的分隔线。大屏 `.panel` 没有上下 padding
- 背景是 `#06203a → #03101c → #020814`，加 `48px` 网格和上下两团径向光
- 变化中的数字走 `AnimatedNumber`，字体 class 含 `num`
- 页面上没有样例色板之外的新颜色，没有 `4px` 以上的卡片圆角（Logo、告警确认钮除外）
- 饼图、环图的每一块都有 `borderRadius: 6`，块与块之间有 `2px` 缝
