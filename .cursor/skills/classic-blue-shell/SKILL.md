# 经典蓝界面规范

后续界面优化按本规范执行。视觉来源是 `docs/map-monitor-system/index.html`（地图监控 · 明亮蓝白，桌面 1280 × 720）。实现落在浅色经典蓝：`html.sidebar-color-blue:not(.dark)`。

极简白和暗色主题不要套用这套色值和尺寸。

原则：清晰、专业、克制、高效。深色导航承载业务层级，白色卡片承载数据。蓝色只表示当前位置和强调。无渐变、无阴影、无模糊。原稿没有的悬停、禁用、徽标不要补。不造移动端。

三重导航各司其职，不互相替代：侧栏是业务导航，面包屑记录当前位置，页签承载页面切换。

## 改哪里

| 内容 | 文件 |
|---|---|
| 色板、侧栏宽、导航高、页签高 | `src/styles/_variables.scss` |
| 侧栏、导航栏、面包屑、页签、内容区、卡片 | `src/styles/_layouts.scss` 中 `html.sidebar-color-blue:not(.dark)` |
| 新页面 | 页面组件，只消费下面的变量和尺寸 |

壳层尺寸用 CSS 变量（`--sidebar-width`、`--navbar-height`、`--tags-view-height`），不要写死 SCSS 像素。已有令牌的颜色用 `--shell-*` 和 `--menu-*`。图表色、品牌线面、选中图标、头像底只在用到的页面里写，不要再扩一套全局色阶。

## 字体

中文 Noto Sans SC，数字和面包屑分隔符 Inter。字距全部为 0。行高默认 AUTO；只有指标数字和纬度标注使用显式行高，不要把纬度的 18px 并进 AUTO。

工程正文仍是系统字体栈。落地时跟字号和字重，不要为了对稿单独引入未加载字体。

## 壳层

原稿只展示展开侧栏。收起按钮在顶栏，收起态不是原稿内容；沿用现有 `--sidebar-width-collapsed: 72px`，不要另造收起视觉。

- 侧栏展开 196px，内边距 16px，行间距 8px。内部菜单宽 164px。侧栏高度随视口，下方留白不是空菜单行。
- Logo 高 44px，图标 26px，标题 18px / 700 / `#E9F0FB`，图标与标题间距 10px。
- 一级菜单高 42px，图标 18px，字号 13px，图标与文字间距 12px，水平内边距 12px。展开箭头 12px，靠右。
- 子菜单高 40px，图标 16px，字号 13px，图标与文字间距 10px，左内边距 28px。
- 当前子项：底 `#203861`，字 `#AFC9FF` / 500，图标 `#86ACFF`，圆角 10px，右内边距 12px。父级有选中子项时只保持 `#E9F0FB` / 500，不要加主色底。
- 顶栏高 60px，白底，左右内边距 24px，子项间距 20px。从左到右：收起 24px、面包屑（占满剩余）、全屏 24px、账户、设置 24px。
- 面包屑 13px。上级 `#66758B` / 400，分隔符 Inter `#A9B4C5` 且左右 12px，当前页 `#1B2B43` / 500。
- 账户区高 36px：头像 32px、圆角 16px、底 `#E6EEFC`，与名称间距 10px。名称 13px / 500 / `#1B2B43`。
- 页签条高 40px，背景 `#EDF1F6`，左内边距 24px，页签间距 8px，无上边框。页签高 28px、圆角 7px、字号 12px。未选中白底 `#66758B`；当前 `#DFEAFE` 底、`#2563EB` 字、字重 500，关闭图标 12px，与文字间距 10px。

图标只用原稿尺寸：12、16、18、24、26、32。不重画路径，不改原色。

## 内容区

画布 1280 × 720。主内容宽 = 视口 − 196，内边距 24px，可用内容宽 1036px。页面背景 `#F4F6FA`。区块顺序：四指标行，然后并排图表。

- 卡片与列表表面（`el-card`、`.page-surface`、`.filter-section`）：白底、圆角 16px、无边框、无阴影。卡片内边距 24px，标题 16px / 500 / `#1B2B43`，标题下不要分割线。
- 指标卡 247 × 100，四等宽，间距 16px，内边距 18px。标签 13px / `#66758B`，与数字间距 8px。数字 28px / 600。默认数字 `#1B2B43`；在线率、充电车辆数用 `#2563EB`。一组里至多一张卡用 `--shell-soft`，这张卡的数字仍用 `#1B2B43`。
- 指标行与图表间距 24px。双图间距 20px，同高 448px：位置散点图 630px，车型里程条形图 386px。
- 散点图标题 16px / 500。条形图标题 14px / 500。刻度 Inter 12px；纬度行高 18px。网格 1px `#E4E9F1`。条形 `#4E83ED`、圆角 3px。状态色只用在线、充电中、告警、离线四色。
- 新列表页的内容容器加 `page-surface`，不要另做灰底或细边框卡片。

## 优化时的约束

1. 先判断当前是否在改经典蓝浅色壳。不是就停用本规范。
2. 新样式放进已有的 `html.sidebar-color-blue:not(.dark)` 块，或在页面里引用 `--shell-*`。
3. 不改登录页配色，不把壳层色写进暗色主题。
4. 不新造圆角、阴影、边框、渐变和字号阶梯。
5. 不补原稿未展示的悬停、禁用、徽标，也不重做收起侧栏。
6. 改完后在经典蓝浅色、左侧布局下核对：整体色板、侧栏选中态、面包屑、顶栏和页签、内容区背景与卡片。地图监控页再核对指标行和双图尺寸。
