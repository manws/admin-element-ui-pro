# 网络请求模块说明

## 一、整体架构

```
请求流程：
页面/Store → API 模块 → request.ts (Axios) → 请求拦截器(注入Token) → 后端
                                              ← 响应拦截器(统一处理/自动存Token) ←
```

```
src/
├── utils/
│   ├── request.ts          # Axios 实例 + 拦截器（核心）
│   └── auth.ts             # Token 存取 + 权限判断 + 登录重定向
├── api/
│   ├── types.ts            # 统一类型导出（re-export @/types/api）
│   ├── auth.ts             # 认证 API（登录/登出）
│   ├── file.ts             # 文件 API（上传/删除/下载）
│   └── system/
│       ├── user.ts         # 用户 API（用户信息/CRUD/个人中心等）
│       └── menu.ts         # 菜单 API（路由列表/菜单CRUD）
├── enums/
│   └── api.ts              # API 响应码枚举
├── types/
│   └── api/
│       ├── common.ts       # 通用类型（ApiResponse/PageResult/OptionItem）
│       └── auth.ts         # 认证类型（LoginRequest/LoginResponse）
├── constants/
│   └── index.ts            # 存储键名（Token 相关）
└── .env.development        # 环境变量（API 地址/端口）
```

## 二、核心模块详解

### 2.1 Axios 实例 — `src/utils/request.ts`

**基础配置：**

| 配置项 | 值 | 说明 |
|--------|-----|------|
| baseURL | `VITE_APP_BASE_API`（默认 `/dev-api`） | 通过 Vite 代理转发 |
| timeout | 50000ms | 请求超时时间 |
| Content-Type | `application/json;charset=utf-8` | 默认 JSON |
| paramsSerializer | `qs.stringify` (repeat 模式) | 数组参数序列化 |

**请求拦截器：**
- 自动注入 `Authorization: Bearer {token}` 请求头
- 如果 `headers.Authorization === "no-auth"`，则跳过 Token 注入

**响应拦截器 — 成功响应：**
- `responseType` 为 `blob`/`arraybuffer` → 直接返回原始 response
- **自动续期**：如果响应头中包含 `new-token`，自动存储新 Token
- 业务码 `code === "00000"` → 直接返回 `data`（解包）
- 其他 → `ElMessage.error(msg)` + reject

**响应拦截器 — 错误响应：**

| 业务码 | 处理逻辑 |
|--------|----------|
| `A0230` (Token 无效) | 跳转登录页 |
| `A0231` (Token 过期) | 跳转登录页 |
| `A0301` (权限不足) | 刷新权限快照 + 提示 |
| 网络断开 | `ElMessage.error("网络连接失败")` |
| 其他错误 | `ElMessage.error(msg)` |

### 2.2 Token 管理 — `src/utils/auth.ts`

采用**单 Token 模式**，后端每次响应可通过 `new-token` 响应头下发新 Token，前端自动存储实现续期。

**`AuthStorage` 对象：**

| 方法 | 说明 |
|------|------|
| `getAccessToken()` | 根据"记住我"从 localStorage 或 sessionStorage 读取 |
| `setToken(token, rememberMe)` | 存储 Token，根据 rememberMe 选择存储位置 |
| `clearAuth()` | 清除 Token（localStorage + sessionStorage） |
| `getRememberMe()` | 获取记住我状态 |

**存储键名（`src/constants/index.ts`）：**
- `vea:auth:access_token`
- `vea:auth:remember_me`

**其他导出：**
- `hasPerm(value, type)` — 权限判断（支持按钮权限和角色判断，超级管理员 `ROOT` 角色拥有所有权限）
- `redirectToLogin(message)` — 重定向登录页（重置状态 + 跳转 + 保留 redirect 参数）

### 2.3 API 响应码 — `src/enums/api.ts`

```typescript
export const enum ApiCodeEnum {
  SUCCESS              = "00000",  // 成功
  ACCESS_TOKEN_INVALID = "A0230",  // 访问令牌无效
  REFRESH_TOKEN_INVALID= "A0231",  // 令牌过期（兼容保留）
  PERMISSION_DENIED    = "A0301",  // 权限不足
  CHOOSE_TENANT        = "A0250",  // 需要选择租户
}
```

### 2.4 统一响应结构 — `src/types/api/common.ts`

```typescript
interface ApiResponse<T = any> {
  code: string;    // 响应码
  data: T;         // 业务数据
  msg: string;     // 响应消息
}

interface PageResult<T> {
  list: T[];       // 列表数据
  total: number;   // 总记录数
}

interface BaseQueryParams {
  pageNum: number;
  pageSize: number;
  sortBy?: string;
  order?: string;  // ASC | DESC
}
```

> 以上类型在 `src/types/global.d.ts` 中声明为全局类型，无需 import 可直接使用。

## 四、Token 认证流程

```
用户登录
  └→ POST /auth/login → 返回 { accessToken }
      └→ AuthStorage.setToken(token, rememberMe) 存储

普通请求
  └→ 请求拦截器自动带上 Authorization: Bearer {token}
      └→ 响应头如果有 new-token → 自动更新存储（实现续期）

Token 过期（A0230 / A0231）
  └→ 直接跳转登录页

用户登出
  └→ DELETE /auth/logout
      └→ AuthStorage.clearAuth() 清除 Token
```

## 六、新增 API 模块示例

```typescript
// src/api/example.ts
import request from "@/utils/request";

const EXAMPLE_BASE_URL = "/api/v1/examples";

const ExampleAPI = {
  /** 获取列表 */
  getList(params: BaseQueryParams) {
    return request<any, PageResult<any>>({
      url: EXAMPLE_BASE_URL,
      method: "get",
      params,
    });
  },

  /** 新增 */
  create(data: any) {
    return request({
      url: EXAMPLE_BASE_URL,
      method: "post",
      data,
    });
  },
};

export default ExampleAPI;
```

**约定规范：**
1. 每个 API 模块导出一个默认对象（`XxxAPI`）
2. 基础路径使用 `const XXX_BASE_URL = "/api/v1/xxx"` 定义
3. 返回类型通过 `request<any, ResponseType>()` 泛型指定
4. 类型定义放在 `src/types/api/` 下
