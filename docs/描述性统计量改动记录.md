## 一、输入区域：表格式数据输入

### 改动说明
将原有的 `<el-input type="textarea">` 改为**双模式输入**：表格输入（默认）+ 文本输入（备用），通过 `el-radio-group` 切换。

### 表格输入模式
- **布局**：用 `<div>` flex 布局模拟表格（非 `<table>`，避免 sticky 兼容问题）
- **结构**：固定表头 `.data-grid-header` + 可滚动数据区 `.data-grid-body`（`max-height: 260px; overflow-y: auto`）
- **列数**：5 列（`tableCols = 5`），每行 5 个数据
- **初始行数**：20 个单元格（4 行 × 5 列）
- **工具栏**：「添加 5 行」「添加 10 行」「粘贴导入」三个按钮
- **粘贴导入**：调用 `navigator.clipboard.readText()`，支持 Excel 复制、逗号/空格/换行/制表符分隔
- **键盘导航**：`Tab` / `Enter` 自动跳到下一个单元格，到末尾自动追加新行
- **实时计数**：右上角 badge 显示已输入有效数据个数

## 二、新增统计指标

### 新增的 `stats.ts` 工具函数

| 函数 | 说明 |
|------|------|
| `geometricMean(arr)` | 几何平均数（含非正值返回 NaN） |
| `harmonicMean(arr)` | 调和平均数（含零值返回 NaN） |
| `trimmedMean(arr, 0.05)` | 截尾均值，两端各去 5% |
| `meanCI(arr, alpha)` | 均值置信区间，返回 `{ lower, upper }` |
| `fmtP(p)` | P 值格式化，`< 0.0001` 时显示 `< 0.0001` |
| `skewnessZTest(arr)` | 偏度系数 Z 检验 |
| `kurtosisZTest(arr)` | 峰度系数 Z 检验 |
| `chiSquareCDF(x, df)` | 卡方分布 CDF |
| `chiSquareInv(p, df)` | 卡方分布逆函数（二分搜索） |

## 六、Bug 修复

### 1. 箱线图不显示
**根因**：`src/components/ECharts/index.vue` 按需加载只注册了 `BarChart, LineChart, PieChart`，缺少 `BoxplotChart`。
**修复**：
```ts
import { BarChart, LineChart, PieChart, BoxplotChart } from "echarts/charts";
echarts.use([..., BoxplotChart, ...]);
```

### 2. 均值 95%CI 上下限反转
**根因**：`normInv()` 函数在 `p > 0.5` 时（如 `p=0.975`）符号处理有误，返回负值。
**修复**：用 Peter Acklam 高精度算法替换，分三段（左尾/中间/右尾）处理：
```ts
export function normInv(p: number): number {
  // pLow = 0.02425, pHigh = 1 - pLow
  // p < pLow: 左尾公式
  // pLow <= p <= pHigh: 中间段有理逼近
  // p > pHigh: 右尾公式（取负翻转）
}
```
此修复影响所有使用 `normInv` 的模块（二项分布CI、泊松分布CI、Z检验等）。
