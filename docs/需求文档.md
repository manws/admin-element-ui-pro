# 首都机场电动车辆安全运营监控管理平台 — 需求文档

> 本文档基于《项目需求.docx》（谈判文件第三章）与《应答文件.docx》核实、提取、整理而成，
> 作为平台功能开发的唯一基准，并作为自动化需求/功能检查的对照依据。

## 1. 项目概述

供应商为首都机场提供飞行区内电动车辆安全运行监控管理平台。平台运行及数据服务器硬件资源由
采购人提供，应答人负责对服务器及数据进行运维，将机场飞行区内现存及新增电动车辆全部纳入监控。

- 现状约 **1900** 余辆电动汽车，预计 2029 年空侧区域总量约 **2800** 辆（通用车 1600 辆、特种车 1200 辆）。
- 服务期：合同签订生效之日起 **3 年**；保证期：服务期满后 **3 年**。
- 数据至少保存 **3 年**，数据资产归属采购人，采购人可实时导出。

## 2. 平台服务具备的主要功能（开发范围）

> 说明：谈判文件第三章（二）为功能需求，本文档据此拆解为可追踪的功能点（编号 F-xx）。
> 运行服务、服务要求、售后要求等流程性条款由《应答文件》承诺落实，其前端体现集中在
> 「报告中心」「告警管理」「消息推送」等功能中。

### 2.1 登录（F-01）

| 编号 | 功能点 | 需求描述 | 对应页面/路由 |
|------|--------|----------|---------------|
| F-01-01 | 账号密码登录 | 用户名 + 密码登录 | `/login` |
| F-01-02 | 双因素认证 | 登录界面开启双因素认证（TOTP 动态口令 / 短信验证码），密码验证后二次验证，连续 3 次失败锁定 | `/login` |
| F-01-03 | 角色权限体系 | 根据登录用户角色显示不同页面数据（RBAC） | 全局 |

## 4. 验收标准

1. 所有 F-01 至 F-06 功能点在页面中可访问、有数据、可交互（Mock 数据支撑）。
2. 登录启用双因素认证流程。
3. 总览页展示热力图、充电曲线、核心指标卡、单车里程、车辆状态、安全评估、最新告警。
4. 监控预警模块包含地图位置、统计面板、充电热力图、车辆列表、单车详情、历史轨迹、告警管理、消息推送记录。
5. 基础数据模块含车辆、终端类型、电池类型、BMS 厂家四类管理。
6. 授权管理支持用户档案与角色权限。
7. 报告中心支持周报/月报/半年报/年报及各类专项报告。
8. `npm run build`（或 `vue-tsc` + `vite build`）通过，无类型错误。
9. 自动化检查脚本 `node scripts/check-requirements.mjs` 全部通过。
